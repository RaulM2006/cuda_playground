# CUDA Playground

A simple project template for high-performance C++ and CUDA development.

## Prerequisites
- **OS**: Windows 10/11 (x64)
- **Compiler**: Visual Studio 2022 (with C++ Desktop Development workload)
- **CUDA**: NVIDIA CUDA Toolkit (v12.0 or higher)
- **Build System**: CMake (v3.18+)

## How to Build
1. Open the folder in **VS Code**.
2. Install the **CMake Tools** and **C/C++** extensions.
3. Select a Kit (e.g., `Visual Studio Community 2022 Release - amd64`).
4. Press `F7` or click **Build** in the status bar.

## How to Run
- Use the **Play** button in the VS Code status bar or run `./build/bin/Debug/main.exe`.
